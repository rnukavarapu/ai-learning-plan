# Downloaded Resources

Most of the courses in `../learning-plan.md` are web-based (docs, video, interactive) and don't have a PDF form. These are the ones that do — downloaded here so you have offline copies.

## whitepapers/ — Business/strategy PDFs (optional, real-world context)

Not required for the learning path — these are about how this technology plays out in organizations, useful if you're curious beyond your own projects.

- [**openai-practical-guide-to-building-agents.pdf**](whitepapers/openai-practical-guide-to-building-agents.pdf) — OpenAI's whitepaper on agent architecture, when to build one, orchestration patterns, guardrails. Best paired with Phase 4.
- [**openai-identifying-and-scaling-ai-use-cases.pdf**](whitepapers/openai-identifying-and-scaling-ai-use-cases.pdf) — Framework for evaluating and prioritizing AI initiatives across an organization.
- [**openai-ai-in-the-enterprise.pdf**](whitepapers/openai-ai-in-the-enterprise.pdf) — Case studies and lessons from real-world AI rollouts.

## papers/ — Foundational research papers (technical depth)

These are the original papers behind concepts referenced throughout the plan. Not required reading end-to-end — skim the abstract/intro/conclusion of each; that's usually enough to solidify the concept without a full academic read.

- [**attention-is-all-you-need.pdf**](papers/attention-is-all-you-need.pdf) — The original Transformer paper (Vaswani et al., 2017). Pairs with Phase 1 (the mechanism behind every LLM you'll use).
- [**chain-of-thought-prompting.pdf**](papers/chain-of-thought-prompting.pdf) — Wei et al., 2022. The paper behind the "chain-of-thought" prompting technique referenced in Phase 1.
- [**react-reasoning-and-acting.pdf**](papers/react-reasoning-and-acting.pdf) — Yao et al., 2022. The ReAct pattern (reason → act → observe loop) underlying most modern agent frameworks. Pairs with Phase 4.
- [**retrieval-augmented-generation-original.pdf**](papers/retrieval-augmented-generation-original.pdf) — Lewis et al., 2020. The original RAG paper. Pairs with Phase 3.
