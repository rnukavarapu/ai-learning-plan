Resources (PDFs & repos)

See also ../reference-repos/ for the 4 GitHub repos referenced inline in ../learning-plan.md (Phases 1-4) — cloned locally rather than listed here, to keep this to what's actually used.

Downloaded Resources

Most of the courses in ../learning-plan.md are web-based (docs, video, interactive) and don't have a PDF form. These are the ones that do — downloaded here so you have offline copies.

whitepapers/ — Business/strategy PDFs (optional, real-world context)

Not required for the learning path — these are about how this technology plays out in organizations, useful if you're curious beyond your own projects.

  • openai-practical-guide-to-building-agents.pdf — OpenAI's whitepaper on agent architecture, when to build one, orchestration patterns, guardrails. Best paired with Phase 4.
  • openai-identifying-and-scaling-ai-use-cases.pdf — Framework for evaluating and prioritizing AI initiatives across an organization.
  • openai-ai-in-the-enterprise.pdf — Case studies and lessons from real-world AI rollouts.

papers/ — Foundational research papers (technical depth)

These are the original papers behind concepts referenced throughout the plan. Not required reading end-to-end — skim the abstract/intro/conclusion of each; that's usually enough to solidify the concept without a full academic read.

  • attention-is-all-you-need.pdf — The original Transformer paper (Vaswani et al., 2017). Pairs with Phase 1 (the mechanism behind every LLM you'll use).
  • chain-of-thought-prompting.pdf — Wei et al., 2022. The paper behind the "chain-of-thought" prompting technique referenced in Phase 1.
  • react-reasoning-and-acting.pdf — Yao et al., 2022. The ReAct pattern (reason → act → observe loop) underlying most modern agent frameworks. Pairs with Phase 4.
  • retrieval-augmented-generation-original.pdf — Lewis et al., 2020. The original RAG paper. Pairs with Phase 3.

Not available as PDFs (read on the web instead)

  • Anthropic's "Building Effective Agents" — anthropic.com/engineering/building-effective-agents
  • Anthropic Academy courses — interactive, academy.claude.com
  • Jurafsky & Martin, "Speech and Language Processing" (3rd ed. draft) — web.stanford.edu/~jurafsky/slp3 — the classic NLP textbook, kept free by the authors themselves (not downloaded/mirrored here since it's an actively-revised multi-chapter draft — the live page is the authoritative version). See Phase 1 and Phase 3 for which chapters pair with what.
  • Google's Kaggle "5-Day Gen AI Intensive" whitepapers — these exist but sit behind a JS-rendered Kaggle page; couldn't fetch a stable direct-download link. If you want them, go to kaggle.com/learn-guide/5-day-genai and download manually (free, no paywall).
